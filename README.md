# Student Performance Prediction Using Machine Learning

## Overview

This project uses machine learning to predict whether a student will answer a question correctly based on historical interaction data and behavioral patterns.
The goal is to identify patterns in user performance and build a classification model that can support intelligent learning systems.

Riiid Labs, an AI solutions provider delivering creative disruption to the education market, empowers global education players to rethink traditional ways of learning leveraging AI. With a strong belief in equal opportunity in education, Riiid launched an AI tutor based on deep-learning algorithms in 2017 that attracted more than one million South Korean students. This year, the company released EdNet, the world’s largest open database for AI education containing more than 100 million student interactions.


## Business Use Case
This type of model can be used in educational platforms to:

* Identify students who may need additional support
* Personalize learning paths based on performance
* Improve engagement and learning outcomes
* Support adaptive learning systems

## Project Steps
* Data cleaning and preprocessing
* Feature engineering from interaction data
* Training classification models (e.g., Logistic Regression, Tree-based models)
* Model evaluation using accuracy and F1-score
* Analysis of important features


## Results

* Built a classification model to predict correct vs incorrect answers
* Evaluated performance using standard classification metrics
* Identified key features influencing student performance
##Tools & Technologies

* Python
* pandas
* NumPy
* scikit-learn

## Project Purpose

This project demonstrates how machine learning can be applied to behavioral data to generate insights and predictions that support decision-making systems.
